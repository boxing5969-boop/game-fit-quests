# 블루 리그 교육 도해 (제안 · 미연결)

레벨 11–20 설계서에 쓰는 손그림 도해입니다. **아직 앱 화면에 연결하지 않았습니다.**

| 파일 | 내용 |
|---|---|
| `concept.svg` | 블루 리그가 만드는 것 — 화이트는 물러나고, 블루는 제자리에서 피하고 되친다 |
| `L11.svg` | 훅 — 앞발이 돌아야 주먹이 나간다 |
| `L12.svg` | 어퍼 — 무릎이 펴지며 주먹이 올라간다 |
| `L13.svg` | 바디 — 허리를 접지 말고 무릎으로 낮춘다 |
| `L14.svg` | 연타 — 머리/몸통 높이를 바꿔가며 친다 |
| `L15.svg` | 슬립 — 발은 그대로, 머리만 중앙선 밖으로 |
| `L16.svg` | 위빙 — 훅은 옆으로 못 피한다, 밑으로 지나간다 |
| `L17.svg` | 카운터 — 세 박자냐 한 박자냐 |
| `L18.svg` | 미트 — 내 박자가 아니라 코치 박자 |
| `L19.svg` | 각도 — 정면은 막힌다, 각을 열면 못 막는다 |
| `L20.svg` | 심사 — 레드 스파링으로 가는 안전 게이트 |

## 왜 사진이 아니라 도해인가
"앞발 뒤꿈치를 안쪽으로 비튼다" 같은 지시는 생성 이미지로 정확히 그려지지 않고 한글 라벨도 깨집니다.
손으로 그린 SVG 는 라벨이 정확하고, 용량이 3KB 내외이며, 밝은/어두운 배경 양쪽에서 읽힙니다.

## 색 규칙
`var(--토큰, 폴백)` 형태라 CSS 토큰이 있는 문서에서는 테마를 따르고,
`<img>` 로 불러오면 폴백(밝은 색)이 적용돼 앱의 검정 배경에서 읽힙니다.
민트 = 맞는 동작 / 주황 = 틀린 동작 / 금색 = 상대.

## 연결하기 전에 정리해야 할 것
블루 레벨 제목이 지금 **세 군데에서 서로 다릅니다.**

1. `src/data/allLevelsData.ts` (앱 레벨 상세 화면) — 스트레이트 회전 / 원투 연결 / 리드 훅 입문 / 어퍼컷 입문 / 콤비 리듬 …
2. DB `levels` · `missions` — 잽·스트레이트 강화 / 훅 입문 / 쉐도우복싱 / 미트 훈련 / 샌드백 드릴 …
3. 설계서 제안 — 훅 단련 / 어퍼컷 / 바디 / 연타 / 슬립 / 위빙 / 카운터 / 미트 / 각도 / 심사

셋을 하나로 확정하기 전에 도해를 화면에 붙이면 제목과 그림이 어긋납니다.
확정 후 `src/data/curriculumImages.ts` 의 `levelHeroImage()` 에서 해당 레벨만
`/curriculum/blue/L{n}.svg` 로 바꾸면 기존 갤러리 렌더( `<img onError>` 로 안전 )가 그대로 씁니다.
