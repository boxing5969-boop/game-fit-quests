# 블루 리그 교육 도해 (제안 · 미연결)

레벨 11–20 설계서에 쓰는 손그림 도해입니다. **아직 앱 화면에 연결하지 않았습니다.**
앱에 이미 있는 레벨 교육 다이어그램(`/assets/curriculum/L{n}.png`)과 같은 언어로 그렸습니다 —
흰 카드 · 검정 복서 실루엣 · 초록 화살표 · 노란 섹션 라벨.

## 설계 원칙 — 회피 먼저, 그다음 무기와 연결

화이트의 방어는 전부 백스텝이라 거리가 벌어져 되칠 수가 없습니다.
그래서 블루는 **회피(L11)부터 시작하고**, 이후 `무기 하나 → 그 무기로 시작하는 3연타를 회피 3종 모두에 붙이기`를 세 번 반복합니다.
한 번 피하면 **최소 세 방** — 한 방만 치면 상대가 곧바로 되돌려치기 때문입니다.
세 방은 **손과 회전이 번갈아야** 한 방의 끝이 다음 방의 시작이 됩니다.
L17이 끝나면 **회피 3종 × 무기 3종 = 9조합**이 전부 3연타로 닫힙니다.

| 파일 | 레벨 | 내용 |
|---|---|---|
| `concept.svg` | — | 화이트는 물러나 거리가 벌어지고, 블루는 제자리에서 피해 되친다 |
| `L11.svg` | 회피 3종 | 슬립(직선) · 위빙(훅) · 더킹(상단) — 발은 셋 다 제자리 |
| `L12.svg` | 훅 | 팔꿈치 90° · 앞발이 돈다 · × 팔만 휘두름 |
| `L13.svg` | 훅 3연타 | 세 회피 각각에서 훅으로 시작하는 3연타 — 손·회전이 번갈아 간다 |
| `L14.svg` | 어퍼컷 | ① 무릎을 굽힌다 ② 펴며 올린다 · × 팔만 들어올림 |
| `L15.svg` | 어퍼컷 3연타 | 어퍼로 가드를 띄우고 훅·직선으로 마무리하는 3연타 |
| `L16.svg` | 바디 | ○ 무릎으로 낮춘다 · × 허리를 접는다 |
| `L17.svg` | 바디 3연타 | 몸통으로 가드를 내리고 머리로 마무리 — 아홉 조합 완성 |
| `L18.svg` | 연속 교환 | 회피 → 3연타 → 회피 → 3연타. 두 사이클이 스파링 한 번의 단위 |
| `L19.svg` | 랜덤 반응 | 직선→슬립·훅 / 훅→위빙·어퍼 / 상단→더킹·바디 |
| `L20.svg` | 타이틀매치 | 레드 스파링으로 가는 안전 게이트 |

## 왜 사진이 아니라 도해인가
"앞발 뒤꿈치를 안쪽으로 비튼다" 같은 지시는 생성 이미지로 정확히 그려지지 않고 한글 라벨도 깨집니다.
손으로 그린 SVG 는 라벨이 정확하고, 한 장에 4–8KB이며, 휴대폰 폭에서도 글씨가 읽힙니다.

## 그리기 규칙
- 카드: 흰 배경 + 16px 라운드. 어두운 앱 배경 위에 그대로 얹힙니다.
- 사람: 검정 실루엣 = 나 / 회색 실루엣 = 상대·원래 자리.
- 색: 초록 = 맞는 동작·움직임, 주황 = 틀린 동작, 노랑 = 섹션 라벨·상대 공격.
- 카드마다 맨 아래 한 줄로 "그래서 뭐"를 적습니다.

## 연결하기 전에 정리해야 할 것
블루 레벨 제목이 지금 **세 군데에서 서로 다릅니다.**

1. `src/data/allLevelsData.ts` (앱 레벨 상세 화면) — 스트레이트 회전 / 원투 연결 / 리드 훅 입문 / 어퍼컷 입문 / 콤비 리듬 …
2. DB `levels` · `missions` — 잽·스트레이트 강화 / 훅 입문 / 어퍼컷 기초 / 콤비네이션 확장 / 쉐도우복싱 / 미트 훈련 / 샌드백 드릴 / 디펜스 연습 / 실전 스텝
3. 설계서 제안 — 회피 3종 / 훅 / 훅 3연타 / 어퍼컷 / 어퍼 3연타 / 바디 / 바디 3연타 / 연속 교환 / 랜덤 반응 / 타이틀매치

셋을 하나로 확정하기 전에 도해를 화면에 붙이면 제목과 그림이 어긋납니다.
확정 후 `src/data/curriculumImages.ts` 의 `levelHeroImage()` 에서 해당 레벨만
`/curriculum/blue/L{n}.svg` 로 바꾸면 기존 갤러리 렌더( `<img onError>` 로 안전 )가 그대로 씁니다.
