# 마이복서153 · 50분 수업 새 틀 (2026-07-30 설계안)

> 대표님 지시: 8블록 → **4블록 전면 개편**. 워밍업은 줄넘기 일변도에서 탈피(밴드·아령·맨몸 다양화).
> 본운동만 레벨(미션) 의존, 나머지 3블록은 전 레벨 공용 풀에서 로테이션.
> 이 문서의 수치·이름은 전부 **제안**이며, 문서 끝 "확정 필요" 목록이 대표·코치 결정 사항이다.

## 1. 50분 4블록 틀

| # | 블록 | 시간 | RPE | 구성 방식 |
|---|---|---|---|---|
| 1 | 🔥 워밍업 | 8~10분 | 2~4 | 공용 풀 10개 중 **2개** (장비 다른 것 1+1, 심박 계열 최소 1) |
| 2 | 🥊 본운동 | 25분 | 4~7 | 리그별 풀 10개 중 **2~3개** — 현재 레벨 미션 커버 드릴 (핵심1+보조1~2) |
| 3 | 💪 마무리운동 | 8~10분 | 5~7 | 공용 풀 10개 중 **2개** (부위 비중복: 하체+코어 등) |
| 4 | 🧘 쿨다운 | 4~5분 | 1~2 | 공용 풀 10개 중 **1~2개** (스트레칭1 + 호흡/정리1) |

- 본운동 25분 산술: 8분 드릴×3 + 전환 30초×2 = 25분, 또는 12분×2 + 전환 1분 = 25분.
- 배치 순서 원칙: 본운동 안에서 **기술 → 접촉 → 체력** 순 (지친 상태 접촉 금지).
- 로테이션: 앱의 기존 일자 시드 로테이션(FNV-1a) 재사용 — 매일 조합이 바뀌되 같은 날은 같은 구성.
- ⚠️ 안전 결정: **아령을 쥔 채 샌드백 타격은 전 블록 금지** (손목·주먹 이중 부하 + 주먹 못 말아쥠). 아령 자극은 워밍업 W9(비접촉 쉐도우)로, 샌드백 등장은 W4(비타격 스텝)로 분리 반영.

## 3. 상세 카드 — 워밍업 풀 (전문)

각 항목 형식: 장비/시간/RPE → 방법(번호) → 코치 큐 → 초보 대체 → 실수 주의.

### W1. 복서 스위치온 — 맨몸 · 4분 · RPE 2~3
발목→무릎→골반→팔→목 순서로 각 10회 돌리고, 마지막 1분 복싱 자세 바운스로 어깨를 텁니다.
큐: "돌리는 관절만 움직이고, 나머지 몸은 조용히." / 대체: 바운스 대신 제자리 걷기 / 주의: 처음부터 빠르게 돌려 목·허리가 꺾이는 것.

### W2. 거울 슬로우 쉐도우 — 맨몸 · 5분 · RPE 2~3
거울 앞에서 잽→원투를 절반 속도로, 칠 때마다 가드·턱·발 확인. 마지막 1분은 오늘 메인 기술 예습.
큐: "빨리 치지 마세요, 오늘은 거울이 상대입니다." / 대체: 펀치 없이 자세+체중이동만 / 주의: 펀치 끝에서만 힘이 들어가 어깨가 솟는 것.

### W3. 사다리 스텝 드릴 — 맨몸(사다리/바닥선) · 5분 · RPE 3~4
인-인-아웃-아웃 전진, 사이드 스텝 복귀, 마지막 바퀴는 칸마다 잽 1회.
큐: "발소리가 작아질수록 잘하고 있는 겁니다." / 대체: 잽 없이 걷기 속도 / 주의: 발만 보느라 가드가 내려가는 것.

### W4. 샌드백 서클 스텝 — 맨몸 · 4분 · RPE 3 (타격 없음)
샌드백에서 한 팔 거리 유지하며 스텝으로 돌기, 30초마다 방향 전환, 마지막 1분 스텝인-아웃.
큐: "백에서 눈을 떼지 마세요 — 상대라고 생각하고." / 대체: 걷기 속도로 방향 전환만 / 주의: 두 발 교차로 중심 붕괴.

### W5. 줄넘기 베이직 바운스 — 줄넘기 · 5분 · RPE 3~4
손목으로만 돌리고 낮게 통통. 30초 뛰기+10초 걷기 반복, 익숙하면 마지막 1분 복서 스텝.
큐: "점프는 바닥에서 종이 한 장 높이만." / 대체: 에어 줄넘기 / 주의: 팔 전체로 돌려 어깨가 먼저 지치는 것.

### W6. 줄넘기 리듬 인터벌 — 줄넘기 · 5분 · RPE 4
40초 편안+20초 빠르게 ×4세트, 마지막 1분 정리. 빨라져도 자세 유지·손목만.
큐: "빨라질 때 어깨가 올라가면 힘이 새는 것." / 대체: 빠른 구간을 에어/잰걸음으로 / 주의: 무릎 편 채 착지.

### W7. 밴드 쉐도우 복싱 — 밴드 · 5분 · RPE 3
밴드를 등 뒤로 돌려 쥐고 잽·투를 70% 속도로 — 밴드가 손을 가드로 당겨줍니다. 30초/15초 반복, 마지막 세트는 맨손.
큐: "팔꿈치를 끝까지 펴지 말고 살짝 남기세요." / 대체: 잽만 / 주의: 팔꿈치 쫙 펴서 반동에 관절 튕김.

### W8. 밴드 가드 스텝 — 밴드 · 4분 · RPE 2~3
손목에 밴드 걸고 팽팽하게 유지하며 사이드 스텝 좌우 10걸음, 이어서 무릎 위로 옮겨 반복.
큐: "밴드가 느슨해지는 순간이 가드가 무너지는 순간." / 대체: 손목 단계만 / 주의: 발 끌기·두 발 붙음.

### W9. 아령 쉐도우 복싱 — 아령 1kg(기본) · 4분 · RPE 3
직선 펀치(잽·원투)만, 절반 속도, 팔꿈치 안 펴짐. 30초 치고 15초 팔 털기 ×4, 마지막 30초 맨손.
큐: "아령은 세게 치는 도구가 아니라, 천천히 정확히 치는 도구." / 대체: 맨손 동일 템포 / 주의: 무게 반동으로 팔꿈치 과신전. **훅·어퍼 금지.**

### W10. 아령 트위스트 스텝 — 아령 1~2kg · 4분 · RPE 3
아령을 가드에 붙이고 뒷발 뒤꿈치 들며 골반 회전 좌우 10회 → 체중 이동+상체 회전 10회 → 앞뒤 스텝에 회전 얹기 1분.
큐: "팔이 아니라 배꼽이 먼저 돈다." / 대체: 아령 없이 회전만 / 주의: 골반은 안 돌고 팔만 흔들림.

## 4. 상세 카드 — 마무리운동 풀 (전문)

전 항목 맨몸(매트·벽만). 3단 강도: 쉽게/기본/강하게.

### F1. 스쿼트 — 하체 · 3×12회 · RPE 5~6
가드 자세 손 위치 → 엉덩이 뒤로 → 허벅지 수평 → 발바닥 전체로 밀며 기립(내쉬기).
연결: 펀치는 다리에서 나온다. / 강도: 의자 터치 8회 / 12회 / 15회+3초 하강.
큐: "무릎은 새끼발가락 방향으로." / 주의: 뒤꿈치 들리고 무릎만 전진.

### F2. 리버스 런지 — 하체 · 3×좌우 8회 · RPE 5~6
한 발 뒤로 크게 → 뒷무릎 바닥 직전 → 앞발로 밀어 복귀. 좌우 교대.
연결: 치고 빠지는 발의 엔진. / 강도: 벽 짚고 6회 / 8회 / 10회+니업.
큐: "가슴은 정면, 몸통은 기둥." / 주의: 뒷무릎 쿵 찧기.

### F3. 월싯 — 하체 · 3×30초 · RPE 5~6
등 전체 벽에 붙이고 보이지 않는 의자, 가드 들고 버티기.
연결: 3분 라운드 스탠스 지구력. / 강도: 얕게 20초 / 30초 / 45초+가드 유지.
큐: "등 전체로 벽을 지그시." / 주의: 무릎이 발끝보다 한참 앞.

### F4. 플랭크 — 코어 · 3×30초 · RPE 5
팔꿈치 어깨 아래, 머리~뒤꿈치 한 줄, 배·엉덩이 힘.
연결: 다리 힘을 주먹까지 전달하는 파이프. / 강도: 무릎 20초 / 30초 / 45초 or 발 들기.
큐: "배꼽을 등 쪽으로." / 주의: 허리 꺾인 채 시간만 채우기 — 무너지면 그 세트 중단.

### F5. 할로우 홀드 — 코어 · 3×20초 · RPE 5~6
허리로 바닥 누르며 어깨·다리 들어 바나나. 허리 뜨면 다리를 올린다.
연결: 바디샷 견디는 몸통 갑옷. / 강도: 무릎 굽혀 15초 / 20초 / 팔 귀 옆 30초.
큐: "허리로 바닥을 눌러 이긴다." / 주의: 다리 너무 낮춰 허리 뜸.

### F6. 사이드 플랭크 — 코어 · 3×좌우 20초 · RPE 5
팔꿈치 어깨 아래, 옆으로 한 줄, 위 손은 가드.
연결: 훅 회전을 만들고 멈추는 옆구리. / 강도: 무릎 지지 15초 / 20초 / 30초+다리 들기.
큐: "옆구리로 몸을 천장으로 밀어." / 주의: 팔꿈치 위치 어긋나 어깨 부담.

### F7. 푸시업 — 상체 · 3×10회 · RPE 5~6
어깨보다 약간 넓게, 팔꿈치 45도, 가슴 하강 → 강하게 밀기.
연결: 펀치 임팩트의 밀어내는 힘. / 강도: 무릎 8회 / 10회 / 15회 or 3초 하강.
큐: "몸 전체가 한 판으로." / 주의: 팔꿈치 90도 벌림.

### F8. 숄더탭 푸시업 — 상체 · 3×6회 · RPE 6
푸시업 1회 + 좌우 어깨 터치 = 1회. 흔들리면 발 넓게.
연결: 한 손 뗀 순간에도 안 흔들리는 어깨·몸통. / 강도: 터치만 6회 / 6회 / 8회+발 좁힘.
큐: "골반은 바닥을 보게 고정." / 주의: 어깨가 손목 위를 벗어남.

### F9. 마운틴 클라이머 — 전신 · 20초/10초 ×6R · RPE 6~7
어깨 손목 위, 무릎 가슴까지 교대 당기기, 엉덩이 솟지 않게.
연결: 라운드 막판 풋워크 심폐 엔진. / 강도: 걷듯 천천히 / 6R / 빠르게 8R(타바타).
큐: "어깨~엉덩이 판자처럼." / 주의: 발끝만 콩콩 — 무릎을 확실히 당기기.

### F10. 버피(점프 없음) — 전신 · 3×8회 · RPE 6~7
가슴 펴고 스쿼트로 앉아 손 짚기 → 발 뒤로(플랭크) → 발 복귀 → 일어서며 가드.
연결: 흐트러져도 곧바로 자세를 되찾는 회복력. / 강도: 걸어서 6회 / 8회 / 푸시업+점프 10회.
큐: "가슴 펴고 앉은 다음에 손." / 주의: 무릎 편 채 착지·털썩 엎드리기.

## 5. 상세 카드 — 쿨다운 풀 (전문)

### C1. 어깨 크로스 풀기 · 4분 — 팔 가슴 앞 당기기 30초 + 머리 뒤 팔꿈치 누르기 30초, 좌우 2바퀴. 큐: "반동 없이 내쉬면서 조금씩." / 주의: 어깨 끌어올린 채 당기기.
### C2. 손목·주먹 풀기 · 3분 — 손끝 아래/위로 당기기 각 20초, 손 바꿔 반복, 털기. 큐: "꺾는 게 아니라 늘이는 것." / 주의: 아플 만큼 확 꺾기.
### C3. 목·어깨선 풀기 · 3분 — 손 등 뒤로 보내고 반대로 기울이기 20초씩 + 앞 숙임 20초 ×2바퀴. 큐: "어깨는 바닥 쪽으로." / 주의: 뒤로 젖히지 않기.
### C4. 고관절 런지 풀기 · 4분 — 무릎 대고 골반 앞으로 밀기 30초씩 좌우 2바퀴. 큐: "허리 젖히지 말고 골반을 밀기." / 주의: 앞무릎 과전진.
### C5. 햄스트링·종아리 풀기 · 4분 — 뒤꿈치 대고 상체 숙임 30초 + 벽 짚고 종아리 30초, 좌우. 큐: "가슴을 발끝으로." / 주의: 반동으로 흔들기.
### C6. 가슴 열기 풀기 · 3분 — 벽에 팔 대고 몸통 돌리기 30초씩 + 등 뒤 깍지 20초. 큐: "가슴이 열리는 만큼만." / 주의: 확 돌려 어깨 앞 통증.
### C7. 박스 호흡 · 3분 — 4초 마시고-4초 멈춤-4초 내쉬고-4초 멈춤 ×8~10회. 큐: "숫자를 속으로 세면 잡생각이 끊긴다." / 대체: 멈춤 없이 4-4만.
### C8. 누워서 배 호흡 · 4분 — 무릎 세우고 배 위 손만 오르내리게 3분, 마지막 팔다리 뻗기. 큐: "내쉬는 숨을 더 길게." / 대체: 벽에 기대앉기.
### C9. 슬로우 쉐도우 리플레이 · 3분 — 오늘 기술 30% 속도 재생, 펀치 끝 1초 멈춤, 마지막 30초 힘 빼고 리듬만. 큐: "코치가 고쳐준 지점에서 일부러 멈추기." / 주의: 느리다고 대충 — 느릴수록 정확히.
### C10. 쿨다운 워킹 & 털기 · 3분 — 천천히 2~3바퀴 걸으며 팔 흔들고 털기, 마지막 반 바퀴 큰 호흡. 큐: "심박은 걸으면서 내려간다." / 주의: 끝나자마자 주저앉기.

## 6. 상세 카드 — 본운동 풀 (전문, 리그별)

공통 규격: 기본 8분(셋업1분+2분×3R+휴식30초×2) / 확장 12분(셋업2분+3분×3R+휴식30초×2).
각 항목: 커버레벨 · 시간 · RPE · 인원 → 방법 → 성공 기준(정량+정성) → 큐 → 초보 대체 → 주의.

### ⚪ 화이트

**WM1. 가드 캐슬** — L1~2 · 8~12분 · RPE 4~5 · 혼자(거울)
스탠스 셋업 → 가드 60초 유지×3세트 → 가드 유지 리듬 스텝 2분×2R → 거울 셀프 점검.
성공: 60초×3 무너짐 0 / 어깨 힘 빼고 호흡 일정. 큐: "턱은 숨기고, 눈은 정면." 대체: 벽 등지고 30초부터. 주의: 팔꿈치 벌어짐.

**WM2. 잽 스나이퍼 100** — L1~4 · RPE 5~6 · 혼자
거울 잽 20 → 샌드백 표적 잽 10×5세트 → 2분×2R 제자리→이동 잽 → (L3+) 잽-잽 더블.
성공: 100회 중 표적 70+ / 매 잽 후 가드 복귀. 큐: "쏘고, 같은 길로 돌아온다." 대체: 거울 잽 50회 절반속도. 주의: 뻗을 때 뒷손 떨어짐.

**WM3. 전진·후진 잽 트랙** — L2~5 · RPE 5~6 · 혼자(바닥선)
라인 전후 스텝 → 스텝인 잽+스텝백 복귀 → 2분×3R 템포 상승 → (L5) 좌우 스텝 추가.
성공: 2분에 스텝-잽 30회, 끊김 3회 이하 / 후진에도 시선 정면. 큐: "앞발이 먼저, 뒷발이 따라온다." 대체: 잽 없이 스텝만. 주의: 후진 시 시선 바닥.

**WM4. 스트레이트 엔진** — L3~5 · RPE 5~6 · 혼자(경량아령)
아령 슬로우 힙회전 2 ×10 → 맨손 정속 10 → 샌드백 가볍게 10×2 → 2분×2R 2만 반복.
성공: 20회 중 뒷발 뒤꿈치 회전 동반 16+ / 몸통이 밀어내는 감각. 큐: "뒷발 뒤꿈치를 돌려서 민다." 대체: 벽 짚고 회전만. 주의: 상체 쏟아짐.

**WM5. 원투 미러 드릴** — L4~7 · RPE 5~6 · 혼자(마지막 R 코치 구령 권장)
슬로우 1-2 → 정속 10연속×3세트 → 2분×3R(R3 구령 반응) → (L7) 스텝인 1-2.
성공: 1-2 10연속 가드 복귀 유지 / 1과 2가 한 동작. 큐: "잽이 문을 열고, 투가 들어간다." 대체: 잽5+투5 분리. 주의: 투에서 턱 들림.

**WM6. 나침반 풋워크** — L5~8 · RPE 5~6 · 혼자(십자 테이프)
전후좌우 스텝 확인 → 피벗90도+복구 좌우 5회 → "스텝-스텝-피벗-잽" 2분×2R → 랜덤 방향 반응.
성공: 피벗 10회 중 복구 8+ / 이동 중 가드 유지. 큐: "발이 멈춘 다음에 친다." 대체: 피벗 빼고 사이드스텝만. 주의: 발 겹침.

**WM7. 쉴드 드릴** — L6~9 · RPE 5~6 · 코치(패드) — 혼자 버전: 샌드백 스윙
코치 패드 잽·2 터치 → 블록·커버 → 블록-잽 반격 → 2분×3R(R3 속도만 상승).
성공: 10회 중 8회 블록 후 복귀 / 막는 순간 눈 안 감음. 큐: "막는 손의 반대 손은 장전." 대체: 어깨 터치로 커버 자세만. 주의: 손이 마중 나감.

**WM8. 인앤아웃 원투 샌드백** — L7~9 · RPE 5~6 · 혼자
사거리 밖 → 스텝인 1-2 → 스텝아웃(뒤/좌/우 로테이션) → 2분×3R(R3 논스톱 리듬).
성공: 진입-이탈 10회 중 8회 / 치고 나올 때 가드 유지. 큐: "치고 나서 두 발이 다 빠져나온다." 대체: 스텝인 잽 단발. 주의: 친 뒤 그 자리에 서 있기.

**WM9. 라운드 서바이버** — L8~10 · RPE 6 · 혼자
줄넘기 1분 예열 → 3분 섀도(화이트 기술만) → 마지막 30초 스퍼트 → 확장 시 3분×2R.
성공: 3분 완주+마지막 30초 잽 스냅 유지 / 호흡 리듬 일정. 큐: "지치면 속도 말고 폼으로 버틴다." 대체: 2분 섀도+1분 스텝. 주의: 후반 가드 하강.

**WM10. 화이트 파이널** — L9~10 · RPE 5~6 · 코치(심사표·영상)
심사 순서 브리핑 → 논스톱 시연+채점 → 영상 리뷰 → 약한 항목 1개 2분 교정.
성공: 5항목 중 4 통과 / 끝까지 자세 유지. 큐: "시험처럼 말고, 평소처럼." 대체: 2항목 부분 리허설. 주의: 긴장으로 속도만 상승.

### 🔵 블루

**BM1. 리드훅 빌더** — L11~13 · RPE 5~6 · 혼자
슬로우 훅(팔꿈치 90도·앞발 피벗) → 정속 10×2 → 샌드백 3 단발→잽-3 → 2분×3R(R3 1-3 리듬).
성공: 20회 중 90도+피벗 동반 15+ / 몸통 회전으로 치는 감각. 큐: "팔꿈치가 주먹보다 먼저 돈다." 대체: 거울 슬로우 15×3. 주의: 스윙처럼 크게 돌아 복귀 늦음.

**BM2. 트리플 플로우 1-2-3** — L11~14 · RPE 5~7 · 혼자/코치(미트)
슬로우 분해(투 끝나기 전 훅 준비) → 구령 리듬 허공 10세트 → 샌드백 2분×3R → 미트 정타 확인.
성공: 10세트 중 밸런스 8+ / 3 이후 가드 복귀 무의식화. 큐: "투가 끝나기 전에 쓰리를 준비한다." 대체: 1-2 정속+3 슬로우. 주의: 3에서 체중 앞쏠림.

**BM3. 어퍼컷 엔진 5·6** — L13~15 · RPE 5~7 · 혼자
무릎 굽혔다 펴며 슬로우 5·6 → 정속 각 10회(주먹 턱 높이 정지) → 샌드백 로우 포지션 2분×2R → (L15) 2-5-2.
성공: 20회 중 무릎 신전 동반 15+ / 상체 세운 채 아래→위 궤적. 큐: "팔이 아니라 다리로 퍼 올린다." 대체: 벽 스치는 슬로우 궤적. 주의: 허리 젖혀 몸통 노출.

**BM4. 콤비 체인 4연타** — L14~16 · RPE 6~7 · 혼자/코치
1-2-3-2 슬로우→정속 → 샌드백 2분×3R(라운드마다 변형: 1-2-5-2/1-1-2-3) → 미트 구령 유도.
성공: 10세트 중 가드 유지 8+ / 연타 중 내쉬기 안 끊김. 큐: "네 개를 한 호흡에 판다." 대체: 1-2-3 정속+2 슬로우. 주의: 뒤로 갈수록 밀기가 됨.

**BM5. 슬립 라인** — L15~17 · RPE 5~6 · 혼자(로프/가상선)
로프 아래 좌우 슬립 슬로우(무릎으로) → 거울 확인 → 슬립-잽·슬립-2 2분×3R → (L17) 전진 슬립-카운터.
성공: 20회 중 시선 정면 16+ / 허리 아닌 무릎으로 피함. 큐: "고개가 아니라 어깨로 피한다." 대체: 제자리 슬로우 슬립만. 주의: 슬립이 커서 다음 동작 소멸.

**BM6. 위빙 아치** — L16~18 · RPE 6~7 · 혼자(로프)/코치(미트 스윙)
U자 위빙 좌우 슬로우 → 미트 훅 궤적 밑 위빙 → 위빙-3, 위빙-위빙-3-2 → 2분×3R(R3 이동 섞기).
성공: 10회 중 복구 8+ / 위빙 중 눈이 정면 유지. 큐: "앉았다 일어나는 건 무릎, 눈은 수평." 대체: 로프 위빙만. 주의: 허리만 숙여 머리가 떨어짐.

**BM7. 슬립-카운터 미트** — L17~19 · RPE 6~7 · 코치(미트)
잽 신호→슬립→2 카운터 → 슬립-2-3 확장 → 2분×3R(R3 좌우 랜덤) → 성공 횟수 콜.

**BM8. 정타율 게이지** — L18~20 · RPE 6~7 · 코치(미트·기록)

성공: 정타율 70%+(30세트 중 21+) / 미트 소리가 "딱" 단타. 큐: "미트를 뚫지 말고 표면을 끊어라." 대체: 2종×5세트. 주의: 정타 욕심에 어깨 힘.

**BM9. 앵글 브레이커** — L19~20 · RPE 6~7 · 혼자/코치

성공: 콤비-앵글-콤비 10세트 중 8 스탠스 유지 / 이동 중 가드·시선 유지. 큐: "정면에 1초 이상 서 있지 마라." 대체: 잽-사이드스텝-잽. 주의: 피벗 없이 옆걸음만.

**BM10. 블루 파이널** — L19~20 · RPE 6~7 · 코치(미트·심사표·영상)

성공: 4항목 중 3 통과 / 전환에도 가드·리듬 유지. 큐: "심사관은 마지막 10초를 기억한다." 대체: 콤비 2개 부분 리허설. 주의: 디펜스 항목에서 리듬 붕괴.

**RM4. 시나리오 섀도** — L24~27 · RPE 6~7 · 혼자(시나리오 지정)
시나리오 지정("전진해 오는 상대" 등) → 3분×2R 교체 → 지정 전술 동작 의식 반복 → 마지막 30초 열세 상황.

**RM5. 약속 대련 🥽** — L25~27 · RPE 6~7 · 파트너+코치 입회 필수

성공: 라운드당 약속 이탈 0 / 터치 강도 일정. 큐: "이기는 연습이 아니라 지키는 연습이다." 대체: 비접촉 리허설. 주의: 후반 흥분해 약속 밖 펀치.

**RM6. 라이트 스파링 입문 🥽** — L26~28 · RPE 6~7(터치 상한) · 파트너+코치 입회 필수
규칙 브리핑(터치·타깃 제한·중단 신호) → 비접촉 워크스루 → 2분×2R+휴식 1분(코치 강도 관리) → 상호 피드백 1개.
성공: 코치 판정 강타 0 / 맞아도 눈 안 감고 등 안 돌림. 큐: "안 다치게 하는 사람이 고수다." 대체: 한쪽 잽만 제한 스파링. 주의: 카운터만 세게 나감. **L26 미만 참여 불가. 세션 접촉 총 6분 이하.**

**RM7. 노 히트 게임 🥽** — L27~29 · RPE 6~7 · 파트너+코치
A 터치 공격만 / B 방어·풋워크만(반격 금지) → 2분×2R 교대 → 피격 수 카운트 → 확장 시 방어자 잽 1개 허용.

**RM8. 스위치 게임 🥽** — L28~30 · RPE 6~7 · 파트너+코치
휘슬로 공/수 강제 전환 → 2분×2R, 전환 후 3초 내 새 역할 → 확장 시 랜덤 휘슬 → 성공률 기록.
성공: 전환 10회 중 3초 내 8+ / 전환 순간 가드 유지. 큐: "빠지는 것까지가 공격이다." 대체: 라운드 단위 교대. 주의: 공격 전환 순간 가드 없이 돌진.

**RM9. 레드 퍼니스** — L21~30 공용 · RPE 7~8 · 혼자(샌드백)

테마 지정("바디만"/"카운터만"/"잽 게임") → 워크스루 1분 → 2분×2R, 이탈 시 즉시 콜 → 자기 평가+새 테마.

**KM5. 티칭 랩** — L35~37 · RPE 3~5 · 파트너(화이트 회원/역할 연기)+코치 참관

**KM7. 코너맨** — L37~39 · RPE 2~4 · 파트너 2인+코치

## 7. ※ 확정 필요 (대표·코치 결정 사항)

1. **4블록 시간 배분** 확정: 워밍업 8~10 / 본운동 25 / 마무리 8~10 / 쿨다운 4~5 (합 50).
2. 워밍업 페어링 규칙(다른 장비 1+1, 심박 최소 1)과 마무리 부위 비중복 규칙의 앱 엔진 반영.
3. 아령 기본 무게(1kg 기본, 2kg 허용 조건 — 예: 블루 이상). **아령+샌드백 타격 전면 금지** 승인.
4. 정량 임계값 현장 캘리브레이션: 블루 정타율 70%, 레드 유지율 80%, 블랙 개선율 20% 등.
5. 스파링 참여 자격에 체급·연령 매칭 기준 추가 여부.
6. 본운동 조립 로직(핵심1+보조1~2, 8분/12분 자동 결정)과 기존 훈련 라이브러리(training_exercises) 카테고리 매핑.
7. 마무리운동 운영: 2개 로테이션(부위 비중복) vs 1개×2라운드.
