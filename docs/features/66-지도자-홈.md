## 코치용 사진 (사진 A안)

- 코치가 회원님께 휴대폰을 보여 드리면 회원님이 직접 읽고 「동의하고 사진 찍기」 → 512px JPEG → 비공개 저장소 `coach-photos/<회원>/face.jpg` → `leader_photo_saved`(동의 문구 판 `coach-photo-v1` · 동의 시각 · 찍은 코치).
- 그 지점 지도진 · 본사만 본다(1시간 서명 주소) · 다른 회원 · TV · 사이니지 없음 · 출입 얼굴 인식에 쓰지 않음(인식 데이터와 따로).
- 수강권 끝나고 `photo_keep_days`(180일) 뒤 · 뺀 사진 · 지점을 떠난 회원 → 크론 `leader-kpi` 가 저장소에서 지우고 `purged_at`.
- 법: 얼굴 인식 특징정보는 민감정보 · 인식용 사진을 다른 목적에 쓰면 원본 · 특징정보 모두 동의를 다시 받아야 한다(개인정보위 생체정보 보호 가이드라인 2021). 인식에 쓰지 않는 일반 사진은 일반 개인정보 — 목적 · 보관 기간을 동의 문구에 적었다(`COACH_PHOTO_CONSENT_LINES`). 문구를 바꾸면 판(`coach-photo-v2`)을 올리고 서버 검사도 같이.
