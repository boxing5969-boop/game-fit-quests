## 1차 흐름 (유튜브 · 2주)
1. **촬영** — 링 옆 가슴 높이 USB 광각 카메라 → 노트북. 1080p 30fps · 소리 없음 · 15분 조각 계속 녹화 · 원본 7일 보관. 프로그램: [external/sparring-recorder](../../external/sparring-recorder/README.md).
2. **기록** — 코치가 앱 타이머 「🥊 스파링 기록」(코치 · 지점장에게만 보이는 칸)에서 오늘 출석한 두 명 고르기 → 「경기 시작」 → 서버가 경기 번호 `<branches.code>-<YYMMDD>-<번호>`(예 `sunreung-261125-07`) · 시작 시각 · 라운드 설정 저장 → 타이머가 끝나면 저절로 경기 끝(「경기 끝」 · 「취소」 단추도).
3. **자르기** — 노트북 `cut` 이 열쇠로 그날 경기 번호 · 시각을 받아 경기마다 `out/<날짜>/<경기 번호>.mp4`(앞 5초 · 뒤 10초 여유). 촬영 안 하는 경기는 자르지 않고 그 원본 조각을 지운다.
4. **올리기** — 코치가 지점 채널 유튜브 스튜디오에 15개씩 끌어다 놓기(제목 = 파일 이름 · 업로드 기본값 일부공개 · 아동용 아님 · 댓글 끔). 매크로 · 프로젝트 쪼개기 금지.
5. **연결** — 지금은 코치가 「오늘 경기」에서 경기마다 유튜브 링크 붙이기(`sparvid_attach_video`). 다음 단계: 채널 목록을 API 로 읽어 제목 = 경기 번호로 저절로 연결(아래 「다음」).
6. **회원** — 연결되면 두 사람에게 알림(밤 10시 ~ 아침 8시는 알림함만) → 훈련 탭 「오늘 할 것」 **내 스파링 영상** 한 줄(영상이 있을 때만) → 영상 · 코치 피드백(시각을 누르면 그 장면) · 커뮤니티 공개 켜기/끄기.
7. **코치 피드백** — 영상 보다가 「여기서 피드백」 → 영상이 멈추고 그 시각 + 글 → 회원 알림. 오삼코치 초안(`kind='ai_draft'`, `status='draft'`)은 코치가 「승인해서 보내기」를 눌러야 회원에게 보인다(초안 만드는 쪽은 아직 없음).
8. **밤 11시** — `sparvid-daily-summary`(pg_cron 14:00 UTC) → 그 지점 코치진에게 「🥊 오늘의 스파링 — 경기 n · 영상 n · 피드백 기다림 n · 촬영 안 함 n(원본도 지우기)」, 전체관리자에게 지점을 모아 한 번. 주소 `/missions?timer=spar`. 끝을 안 누른 경기(2시간 지난 live)는 이때 라운드로 계산한 시각으로 닫는다.

## 촬영해도 되는 사람 (`_sparvid_film_check` — 두 사람 모두 통과해야 `film_ok`)
최신 동의서가 있고 철회 아님 · `video_ok`(동의서 v2 영상 칸) · 만 14세 미만 아님(동의서 칸 또는 생년월일) · 미성년(동의서 또는 생년월일 18세 미만)은 법정대리인 칸. 까닭: 동의서 없음 · 동의 철회 · 영상 동의 없음 · 14세 미만 · 보호자 동의 없음 — 코치 화면에만(`film_block`, 회원은 경기 표를 못 읽음).

- 영상은 **선택 동의**: 「촬영에 동의합니다 / 촬영하지 않습니다」 둘 중 하나를 골라야 제출. 안 해도 스파링은 한다.

## 대표님 할 일 (1차를 켜려면)
1. 지점 유튜브 채널 + 업로드 기본값(일부공개 · 아동용 아님 · 댓글 끔).
2. 구글 클라우드 프로젝트 1개 → YouTube Data API 켜기 + OAuth 동의 화면 「프로덕션」(검수 없이 우리 채널 계정 1개만 — 테스트 상태는 갱신 토큰이 7일이면 끊김) → 채널 목록 읽기. API 심사(감사) 신청은 함께 넣고, 통과하면 노트북 자동 올리기.
3. 카메라 · 노트북(README 준비물) · 링 입구 안내문(아래) 출력 · 코치님 촬영 동의를 링까지.
4. 개인정보처리방침에 한 단락: 스파링 영상(선택) · 유튜브(Google LLC, 미국) 국외 보관 · 보유 기간 · 거부 방법 — 유튜브 서비스 약관 · 구글 개인정보처리방침 링크.
