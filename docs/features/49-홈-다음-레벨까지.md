- 무엇이 보이나: 이름표 「레벨 n까지」(레벨 10 = 「블루 리그까지」) + 주인공 한 줄(「2번 더 오면 돼요」 · 「다음 출석 때 올라가요」 · 「n번 더 오면 심사가 열려요」 · 「승인을 기다려요」 …) + 「미션」 칸.
  - **레벨 1~9** = 「레벨 n 미션」 — 그 레벨의 레벨 미션 영상(`missions` · 워밍업 빼고) 세 줄까지 · 넘으면 맨 아래 「미션 n개 모두 보기」, 아니면 「미션 연습하러 가기」(둘 다 `/missions?open=practice` = 내 레벨 연습하기). 미션 영상이 없는 레벨(블루 · 레드 · 블랙 대부분)은 레벨 데이터(allLevelsData)의 목표 한 줄 — **영상이 있으면 영상만**(레벨 데이터 글과 올린 영상의 레벨 배치가 달라 섞지 않는다 · MyLevelPractice 와 같은 규칙).
  - **레벨 10 · 타이틀매치 신청 흐름**(시범 지점 화이트) = 「타이틀미션」 두 줄(완벽한 자세로 3번 연속 성공 · 같은 동작을 미트로 3번 받아주기 — `TITLE_MISSION_SHORT`, 심사 기준 `titleMissionRules` 를 줄인 말이라 기준이 바뀌면 같이) + 타이틀매치 동작 영상. 단계마다: 신청 전 = 「타이틀매치만 남았어요」 + 「타이틀미션 · 심사 신청」 단추(같은 곳으로 가는 맨 아래 줄은 안 둔다) / 신청함 = 「심사를 기다려요」 / 도전 중 = 「도전 중 · 남은 기회 n번」 / 3번 마감 = 「○월 ○일부터 다시 신청해요」 — 뒤 셋은 단추 대신 맨 아래 「타이틀미션 자세히 보기」. 서버 답이 오기 전에는 단추를 안 보인다.
  - **그 밖의 레벨 10**(다른 지점 화이트 · 블루 …) = 「타이틀매치 동작」 영상 + 회색 한 줄 「○○님이 보고 승인하면 ○○ 리그」.
- 레벨 1~9는 **출석만으로 올라간다**(화이트 3회 · 블루 5회 자동 · 레드 8회 · 블랙 20회 + 45일은 심사) — 미션은 그 레벨에서 익힐 동작이지 레벨업 조건이 아니다. 미션을 조건으로 바꾸려면 서버 규칙(`auto_advance_from_attendance` — 보호 영역)부터라 대표님 결정이 먼저.
