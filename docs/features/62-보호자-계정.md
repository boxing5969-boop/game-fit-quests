# 62 보호자 계정 · 「우리 아이」 · 「운동을 끝낼까요?」

2026-11-23 대표님: 「수험생들이 많이 등록하고 있어서 어머님들이 가끔 늦게까지 안 오면 걱정하시는데 어머님들을 위한 마이복서 153 기능 만들어줘 · 아이들은 출석 뒤 50분부터 '운동을 종료할까요?' 팝업 · 어머님들도 가입 가능하게 · 부모님 인증으로 누구 엄마 누구 아빠 가입하면 몇 시에 와서 얼마나 운동했고 153으로 얼마나 건강과 가치를 얻었는지」 → 계획 보고 → 「추천대로」.

## 결정 (추천대로)
1. 가입 길 두 개: 아이 앱 설정 「엄마 · 아빠 연결」 링크(7일 · 한 번) + 데스크 회원 상세 「보호자 연결 QR」(24시간 · 한 번). 보호자는 카카오로 시작 → 「보호자 계정」(`profiles.account_kind='guardian'`) — 승인함 · 회원 수 · 랭킹에 안 들어간다. 이미 승인된 회원이 보호자가 되면 계정은 그대로, 홈에 「우리 아이」 한 줄.
2. 끊기: 보호자는 언제든 · 만 19세 이상 회원은 앱에서 · 미성년(또는 생년월일 모름)은 데스크에서. 데스크 QR 로 성인 회원에게 온 요청은 회원이 수락해야 이어진다.
3. 끝 기록이 없어도 보호자에게 따로 걱정 알림은 안 보낸다(화면에 「운동 중 1시간 32분째」만).
4. 팝업 대상: 보호자가 연결된 회원 + 생년월일로 미성년인 회원.
5. 보호자 문자(SMS)는 하지 않는다 — 2026-11-24 대표님 「문자 알림은 돈이 들어가니까 하지말자 무료로 할수있는 마이복서 153 앱을 활용할거야」. 보호자 알림은 앱 알림(휴대폰 푸시 · 알림함)만.

## 보호자에게 보이는 것 / 안 보이는 것
- 보임: 오늘 도착 · 운동 중 n분째 · 끝 시각과 분, 이번 달 달력 · 날 수 · 시간, 153에서 운동한 날 · 모두 합한 시간 · 처음 온 날, 레벨 · 다음 레벨까지, 코치 한마디(`coach_day_notes` 최근 3), 153 PB 최고 기록, 최근 운동 10번.
- 안 보임(서버가 아예 안 줌): 메시지 · 커뮤니티 글 · 마음 체크 · 몸무게 · 체지방.
- 보호자 화면의 분은 실제 흐른 분(들어온 시각 ~ 끝 시각). 회원 합계용 `workout_minutes`(최소 66)와 다를 수 있다.

## 알림 (1분 예약 `guardian-tick` → `guardian_tick()`)
- 도착: 그날 첫 출석 → 보호자 「{이름} · HH:MI 체육관 도착」.
- 끝: `ended_at`(운동 끝 단추 · 나갈 때 얼굴 인식) → 「{이름} · HH:MI 운동 끝」 「오늘 N분 운동했어요 · HH:MI ~ HH:MI」.
- 아이: 출석 70분(`remind_min`)에 끝 기록이 없고 보호자가 연결돼 있으면 한 번 「운동 끝나면 「운동 끝」을 눌러 주세요」 → `/home?finish=1`.
- `guardian_notices` (kind, attendance_id, user_id) 로 한 번만. 보호자 도착 · 끝 알림은 밤에도 휴대폰으로, 연결 안내 알림은 22~08시엔 알림함만.
- 출석 표(attendance_logs)에 트리거를 달지 않는다(보호 영역) — 그래서 1분 예약.
