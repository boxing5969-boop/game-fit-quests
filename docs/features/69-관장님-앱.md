## 끄기 · 켜기

- 관장님 숫자만 끄기 = `app_settings.leader_home.owner_branches` 를 빈 배열(지도자 홈은 그대로). 지점장에게 매출 보이기 = `owner_sales_managers` 에 지점 이름.
- CRM 끄기 = `app_settings.leader_home.crm_branches` 를 빈 배열(탭 · 메뉴 칸 · 관장님 숫자 줄의 CRM 길이 함께 사라진다). 다른 지점 켜기 = 지점 이름을 더한다(153OS `branches.name` 과 같은 글자).
- 다른 지점: 153OS `branches.name` 과 앱 지점 이름이 같아야 한다(지금은 글자 맞추기 — ⑤에서 지점 번호 연결). 선릉의 관장 = 대표님(본사) — 다른 지점 관장 표시는 그 지점을 켤 때 더한다.
- AI 관장 모드 끄기 = `app_settings.leader_home.owner_ai_branches` 를 빈 배열(오삼코치는 지금처럼). 하루 한도 = `owner_ai_daily`.
