# 63 얼굴 출석 키오스크 — 출석 · 퇴장 버튼 · 10초 자동 출석

태블릿 · 스마트폰 · 체육관 안드로이드에서 `myboxer153.com/face-kiosk`(또는 설치 앱 「153 얼굴출석」)를 켜 두면, 얼굴을 맞춘 뒤 153OS 출석부 · 마이복서153 · 라이브보드(사이니지)에 출석이 들어간다.

## 흐름 (2026-11-25 대표님 결정)

- 대표님 11/25 17:30 「얼굴인식후 출석누르면 출석이 되고 나갈때 한번더 인식을하는데 인식후 출석 퇴장버튼이 나오면 퇴장 버튼을 누르면 운동 시간 저장 이렇게 가자」
- 대표님 11/25 17:42 「10초 자동출석으로 하자 나갈때 퇴장없이 가는사람은 한시간운동으로 처리하자 퇴장 버튼을 누른사람만 모든 운동 시간 기록하고」

| 상황 | 카드 | 동작 |
|---|---|---|
| 오늘 처음 인식(출석 전) | [출석] · 막대 · '제가 아니에요' | 누르거나 **10초 뒤 자동 출석**. 다음 사람이 먼저 인식되면 앞사람 출석을 화면 없이 확정 |
| 오늘 출석한 회원이 다시 인식 | [출석] [퇴장](퇴장이 크게) | **[퇴장]을 누른 사람만** 그 시각까지 실제 운동 시간 저장 · XP 차액. 안 누르면 10초 뒤 닫히고 **기본 운동 시간**(`workout_default_minutes` = 66분) |
| 앱에서 운동 종료 · 시간 고침을 한 날 | 기록만 | 키오스크 퇴장이 덮지 않는다 |
| 만료 · 미납 · 정지 · 동의 철회 | 사유만(버튼 없음) | 지금과 같음(153OS verify 가 판정) |

- 퇴장을 일찍 잘못 눌렀으면 나갈 때 다시 누르면 그 시각으로 다시 닫힌다(XP 는 차액만 — 두 번 받지 않음).
- 브로제이로 이미 찍힌 날(선릉 · 잠실 · 역삼)도 처음부터 [출석][퇴장] — 같은 날 방문은 1회.
- '기본 운동 시간 = 한 시간'은 66분 그대로(대표님 11/25 23:54 「올리자」 — 전 회원 · 브로제이 포함 같은 값). 60분으로 바꾸려면 `workout_default_minutes()` · `DEFAULT_SESSION_MINUTES`(src/lib/achievement153.ts)를 함께(승급 진행도 · 랭킹 · XP 가 같이 바뀐다).

## 키 (2026-11-25 발견 · 고침)

- 153OS 는 지점 키(`internal_config.face_kiosk_key:<지점 id>`, FC-6)와 옛 공용 키를 받는다. 앱 face-kiosk 는 그동안 앱 공용 키(`internal_sync_config.face_kiosk_key`)만 받아서, **지점 키를 넣은 키오스크는 153OS 판정은 되는데 앱 출석 · 라이브보드가 401 로 조용히 빠졌다**(화면은 '출석 완료' — 앱 체크인 실패를 부가 경로로 삼켰다). 2026-08-03 시범 15번이 앱 출석 0줄인 것과 맞는다(추정).
- 고침: face-kiosk 가 모르는 키를 153OS `/api/face/settings` 에 물어 `scoped + branch_name` 이면 받아 준다(맞음 10분 · 틀림 1분 기억, 153OS 장애는 기억 안 함). 지점 키면 출석 지점도 키에서 정한다(화면이 보낸 이름은 공용 키일 때만). 지점 키는 `checkin` · `state` · `checkout` 만 — 옛 `lookup` · `enroll` · `list`(지점 구분 없음)는 앱 공용 키만(403).
- 키 값은 채팅 · 커밋 · 로그에 쓰지 않는다.
