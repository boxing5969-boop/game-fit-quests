3. 153마인드셋 기능 명세

3.1 기능 개요

153복싱짐으로 돌아온 성인 회원이 운동 직전·직후에 마음을 정돈하는 3분 1라운드 시각화 훈련. RPG 게임형 표현 일절 사용 금지. 회복 / 꾸준함 / 자기 존중 / 전문성 / 지도자 가능성 톤.

복싱은 강해지는 시간이기도 하지만, 나를 다시 좋아하게 되는 시간이기도 합니다.

3.2 사용자 흐름 (7-step)

  1. 시작 화면 — 제목 + 부제 + openingText + "시작하기"
  2. 오늘의 마음 — 6 옵션 중 1개 선택 → 응답 즉시 표시
  3. 마음가짐 — 5 옵션 중 1개 선택 → 설명 즉시 표시
  4. 실천 약속 — 7 옵션 중 정확히 3개 선택 (FIFO: 4번째 클릭 시 가장 오래된 1개 자동 제거)
  5. 3분 플레이어 — 12 세그먼트 × 15초, setInterval 1초 tick. 시작 / 일시정지 / 계속 / 다시시작 / 마무리
  6. 감정 기록 — Textarea 500자, 비워도 저장 가능
  7. 저장 완료 — localStorage 저장 + 마무리 선언문

3.3 두 세션 카탈로그

세션id (변경 금지)title용도
단기 myboxer-153-returned-person 153복싱짐으로 돌아온 사람 오늘의 한 라운드 (운동 직전 마음 정돈)
장기 myboxer-153-one-year-later 1년 뒤, 나는 복싱인이 되어 있다 1년 뒤 자신을 미리 만나는 장기 시각화
session id 변경 금지 — localStorage 기록 호환성 유지를 위해 위 두 id는 영구 보존.

6. 데이터 모델 (콘텐츠)

6.1 타입

type MoodKey = "tired" | "stressed" | "awkward" | "excited" | "want_change" | "future_leader";
type MindsetKey = "return_to_self" | "no_compare" | "one_more_time" | "respect_body" | "becoming_boxer";
type PromiseKey = "breath_back" | "guard_up" | "no_compare_action" | "listen_coach"
                | "retry_after_fail" | "record_emotion" | "thank_self";

interface VisualizationSegment {
  id: number;          // 1..12
  start: number;       // 0..180
  end: number;         // 0..180 (start + 15)
  title: string;
  guide: string;
  narration: string;   // \n 줄바꿈으로 모바일 가독성
}

interface VisualizationSession {
  id: string;          // 영구 식별자 — 변경 금지
  title: string;
  subtitle: string;
  durationSeconds: 180;
  openingText: string;
  closingDeclaration: string;
  segments: VisualizationSegment[];   // 정확히 12개
}

  • Cloudflare Pages 대시보드에서 빌드 상태 확인

git revert <commit-hash>
git push origin main      # Cloudflare Pages 자동 재빌드
