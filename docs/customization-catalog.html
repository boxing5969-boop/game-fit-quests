리그현재 가격 책정 시 참고한 리그 밴드. 실제 해금은 리그 아닌 Lv 또는 블랙 전용 플래그로 결정됨
등급common / uncommon / rare / epic / legendary
현재가격코드에 현재 박혀 있는 price 값 (젬). 0 = 무료
현재해금unlockRules.ts 에 정의된 requiredLevel. 규정 없으면 —
새 가격✎ 결정해서 직접 기입할 빈 셀
새 해금Lv✎ 결정해서 직접 기입할 빈 셀 (1~99 범위, 마스터 트랙 지원)

부가 표기

black레거시 blackOnly 플래그 — 블랙리그 미만 구매 차단 중 (unlockRules 와 병행 운영)
HoFrequirement: "hall_of_fame" — 명예의 전당 입성자만 구매 가능 (level 무관)
Lv.NunlockRules.ts 에 등록된 레벨 게이트. CharacterStudio 에서 자물쇠 표시
—레벨 게이트 없음. 가격만으로 구매 가능 (또는 가격 0 = 즉시 장착 가능)

권장 작업 순서

  1. 이 문서를 인쇄 또는 PDF 로 열고 각 아이템의 새 가격 / 새 해금Lv 컬럼 채움
  2. 결정된 값을 가지고 unlockRules.ts (레벨) + characterCustomizationData.ts (가격) 동시 업데이트
  3. 프리셋에도 레벨 게이트를 넣기로 했다면 unlockRules.ts 에 "preset" 카테고리 신설 + 서버측 purchase_customization RPC 확장
  4. 마이그레이션 기존 회원이 이미 소유한 아이템은 user_owned_customizations 에 기록되어 있어 해금 레벨을 올려도 장착은 가능 (purchase_customization 의 already_owned 분기 보호)
