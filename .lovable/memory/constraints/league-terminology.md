---
name: 리그 용어 통일
description: "계급" → "리그" 전면 변경. DB 컬럼(rank_name 등)은 유지, UI 문구만 "리그"로 통일
type: constraint
---
- "계급" 표현 금지 → 반드시 "리그"로 표기
- "승급" → "리그 승격"
- "계급도" → "리그맵"
- "벨트" 표현 사용 금지
- 표기 형식: "화이트 리그 · 레벨 1" (정식), "화이트 L1" (축약)
- 중복 금지: "화이트 화이트", "레벨 1레벨" 등
- 전체 구조: 4리그 × 10레벨 = 40레벨
- DB 컬럼명(current_rank, rank_name)은 그대로 유지
- formatRank() → "화이트 리그 · 레벨 3" 형식
- formatRankShort() → "화이트 L3" 형식
